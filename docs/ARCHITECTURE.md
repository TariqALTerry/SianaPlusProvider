# صيانة بلس — منصة المزود: architecture and conventions

The product brief is `../Siana/docs/PROVIDER-PLATFORM-PROMPT.md` in the backend repo. It defines every
screen, endpoint, field and error code.

- **Never invent an endpoint, field, status or error code.** If the brief or `src/api/types.gen.ts`
  doesn't have it, the backend doesn't either.
- The controllers under `../Siana/Siana.API/Controllers/Provider/` are the final word on routes.

This repo shares the stack and conventions of the admin dashboard (`../Siana-Dashboard`). Its
infrastructure (`api/`, `components/`, `hooks/`, `lib/`, `i18n/`, `scripts/gen-types.mjs`) was
copied from there and then adapted.

## Stack

- React 18, TypeScript strict, Vite.
- react-router v7: data router with `lazy` routes.
- TanStack Query v5 and TanStack Table v8.
- Tailwind with Radix primitives (shadcn-style, in `components/ui`).
- Forms: react-hook-form + zod.
- i18next: Arabic is the default and RTL; English is LTR.
- dayjs, converting UTC to Asia/Riyadh.
- sonner for toasts, zustand for the auth and theme stores.
- Leaflet + leaflet-geoman + individual `@turf/*` modules, for coverage only.
- Recharts is allowed only on the home page.

## Brand (§3 of the brief)

- **Tokens.** These live in `src/styles/globals.css`, with light and dark values; never hard-code
  hex in components.
  - Brand: `brand-deep`, `brand-deep2`, `brand-teal`, `brand-mint`, `brand-yellow`, `brand-cream`.
  - Base: `primary` (#047760), `background`, `surface`, `foreground` (ink), `muted-foreground`,
    `border` (line), `destructive` (#B42318).
  - Status tones: `tone-*`.
- **Radii.** Use `rounded-md` (8) for controls, `rounded-lg`/`rounded-xl` (14) for cards and
  `rounded-2xl` (22) for hero panels.
- **Hero areas** use `hero-gradient` + `brand-pattern`. The logo mark goes only on light tiles
  (`LogoMark`).
- **Fonts.** IBM Plex Sans Arabic + Inter (`font-latin` for phones, codes and Latin numbers). Use
  `tabular` for money, times and counts.
- **Tone:** one clear primary action per screen, and status as a coloured dot + word
  (`StatusBadge`).
- **Responsive.** Pages must work at phone widths. `DataTable` turns into cards under 768 px:
  - mark the title cell with `meta: { cardTitle: true }`;
  - hide noise on cards with `meta: { cardHidden: true }`.

## Folders

```
src/
  api/          http.ts (the only HTTP config), session.ts, queryClient.ts, keys.ts (root query keys),
                files.ts (fileUrl), types.gen.ts (GENERATED), types.ts
  app/          router, AuthGuard + ProviderGate, AppShell, Sidebar, Topbar, StatusBanner,
                RouteGuard, nav.ts, provider.ts (the provider context), theme
  components/   shared domain components; ui/ = primitives
  features/<x>/ api.ts, i18n.ts, routes.ts, *Page.tsx, components/
  hooks/        useUrlState, useAction, useLang, usePageVisible (usePollingInterval),
                useDebouncedValue, useMediaQuery
  i18n/         index.ts, ar.json/en.json (common namespace ONLY), enums.ts (all enum labels, provider wording §9)
  lib/          format.ts, phone.ts (Saudi mobile helpers), cities.ts, csv.ts, storage.ts, env.ts, utils.ts
```

A feature folder never edits another feature's files, `ar.json`/`en.json`, the router or `app/`.
It owns three files:

- **`routes.ts`** exports `<x>Routes: RouteObject[]`.
  - Each route uses `lazy: () => import('./Page').then(m => ({ Component: m.Page }))`.
  - Each route declares `handle: RouteAccess`:
    - `{ full: true }` for pages that exist only once the organization is Approved/Trial;
    - add `marketplace: true` or `store: true` where it applies.
  - The router already imports every feature's `routes.ts`, and `RouteGuard` enforces the handle.
- **`i18n.ts`** calls `registerTranslations('<ns>', { ar, en })`.
  - Pages import `'./i18n'` and use `useTranslation('<ns>')`.
  - Common strings come from the common namespace: `t('common:actions.save')`.
  - Write natural Arabic first, English second.
- **`api.ts`** holds:
  - typed calls built on `http.get/post/put/patch/delete/upload` (these unwrap the envelope);
  - query-key factories under the root key from `api/keys.ts`.

## Types

`src/api/types.gen.ts` is generated by `npm run gen:types` (`scripts/gen-types.mjs`), the same generator the
dashboard uses.

- **Source:** it reads the backend's C# DTO classes and enums from `../Siana/Siana.Core/DTOs` and
  `../Siana/Siana.Core/Enums`. It does not use the Swagger document.
  - The brief mentions the `/swagger/provider/swagger.json` group. Generating from the C# sources gives the
    same contract without running the API.
  - It covers every DTO, including the `shared` ones.
- **Output:**
  - Enums are string unions (`ServiceItemStatus`), plus `ServiceItemStatusValues` arrays.
  - Nullable C# members become `| null`.
  - Dates are UTC ISO strings.
- **Usage:** import from `@/api/types`. List filters use `ListParams<XListRequest>`.
- **Never edit the generated file.** After a backend DTO or enum change:
  1. run `npm run gen:types`;
  2. fix what `npm run typecheck` reports;
  3. label new enum values in `src/i18n/enums.ts`. The enum test fails until every value has an Arabic and an
     English label.

## The provider context (§6, §7)

- `useProvider()` (from `app/provider.ts`) returns:
  - `org` (`ProviderOrganizationResponse`);
  - `mode`: `onboarding` | `review` | `full`;
  - `isOwner`;
  - `operational`: the server's write gate (Approved, or Trial not yet ended);
  - `trialEnded`, `marketplaceEnabled`, `storeEnabled`.

  It is always loaded: `ProviderGate` waits for it.
- **After any organization write**, invalidate `qk.organization`. The shell then re-reads the status,
  steps, counts and menu.
- **Owner-only actions** must be hidden for supervisors with `isOwner` / `useIsOwner()`. The server
  answers `OwnerOnly`. These actions are: profile PUT, business model, submit, supervisors.
- **Writes for work, tenders and store** return `ProviderNotOperational` unless `operational`. Show
  the actions, but disable them with a short reason when `!operational`. The global handler already
  toasts and refetches.
- **Session-ending codes are handled in `http.ts`** (§4): `AccountSuspended`, `TenantSuspended`,
  `ProviderOrganizationNotFound`, …. Don't handle them in features.

## Rules

1. **Server state lives only in TanStack Query.**
   - Lists use `...listQueryOptions`.
   - The open detail uses `...detailQueryOptions`.
   - Lookups use `LOOKUP_STALE_TIME`.
   - Query functions pass `signal`.
2. **List state lives in the URL.** Every list's filters, tab, page and page size go through
   `useUrlState(schema)`, and setting a filter resets the page.
3. **Paginated lists use `DataTable`**: `rowHref` or `onRowClick`, `onRowHover` prefetch, and
   `filtered` + `onClearFilters`. Non-paginated arrays (Incoming, members) render as cards or simple
   tables, collapsing on phones.
4. **Every mutation goes through `useAction`** inside an `ActionDialog` / `ConfirmDialog` /
   `ReasonDialog`.
   - Restate the target (`SI-10053-2 · صيانة غسالة`) and use `destructive` for reject or delete.
   - Give a required reason where the API requires a note.
   - Never update a status optimistically.
   - One-click actions without a dialog pass `errorToast: true`.
   - Invalidate the entity, its lists, `qk.dashboard`/`qk.incoming`/`qk.board` when counts change,
     and `qk.organization` after organization writes.
5. **Error codes.** Branch on `toApiError(e).errorCode` and display the server `message` (it is
   localized). Structured `details` (e.g. `missingSteps`, `missingCapabilityIds`,
   `{ maxConcurrentJobs, activeJobs }`) can drive richer UI.
6. **Enums render through `StatusBadge` / `EnumText`.** Labels use the provider wording in
   `i18n/enums.ts`. Select options use `enumOptions('X')` + `enumLabel('X', v, lang)`.
7. **Formatting components:**
   - money: `<Money value />`;
   - dates: `<DateTime value />` (Riyadh) or `mode="absolute"`;
   - durations: `<Duration minutes />`;
   - numbers: `<Num />` and `<Percent />`;
   - phones: `PhoneText` (full, `tel:`) or `formatSaudiMobile`;
   - human numbers: `EntityLink` / `HumanNumber`;
   - `…Ar/…En` pairs: `pick(ar, en)` from `useLang()`.
8. **Phone inputs** use `PhoneField` (fixed `+966` and 9 digits) and submit `toSaudiE164(digits)`.
   Cities use `CityInput`.
9. **Commission rates are fractions** in the API. Show them as % with `<Percent />`, `toPercent`.
10. **Uploads** go through `FileUpload` (5 MB, extensions) and `http.upload` / FormData with the
    `file` field. Show returned URLs through `fileUrl()`.
11. **Loading, error and empty states:**
    - loading shows skeletons;
    - errors show `ErrorState` with a retry;
    - empty shows `EmptyState`;
    - business errors inside dialogs show `InlineError` (automatic in `ActionDialog`).
12. **Polling only where §10 says**, always with `usePollingInterval(ms)`:
    - Incoming: 30 s (shared `useIncoming()` from `features/incoming/queries.ts`);
    - dashboard and board: 60 s;
    - bell: 60 s;
    - an open work item in an active status: 30 s.
13. **Heavy libraries load only on their pages.** Maps load only on the coverage tab
    (`components/map/LazyMap`, or Leaflet + geoman directly in the coverage editor; import
    `leafletGlobal` before geoman).
14. **RTL uses logical classes:** `ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`, `text-start`, `text-end`.
15. **Accessibility:** real buttons and links, labels on inputs (`Field`), and Radix dialogs (focus
    trap and Esc).
